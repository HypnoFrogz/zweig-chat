# Grafana: кто и когда пользуется мессенджером

Дашборды по сотрудникам и времени: активность по дням и часам, устройства,
сообщения, звонки, каналы. Grafana читает базу мессенджера напрямую, только
на чтение, — отдельной базы метрик не нужно.

## Что собирается

Бэкенд пишет (`backend/analytics.py`):

| Таблица | Что в ней |
|---|---|
| `activity_hourly` | человек, час (UTC), клиент — одна строка, если был в сети в этот час |
| `session_log` | каждое подключение: начало, конец, длительность, клиент, версия |
| `call_log` | звонки: кто, кому, голос или видео, ответили ли, длительность от ответа |

Клиент определяется так: веб — `web`, десктоп (Electron) — `desktop`,
телефон — `ios`/`android` (новые сборки присылают `platform`), старые
сборки — просто `mobile`.

Сообщения, файлы и каналы берутся из основных таблиц, ничего нового для них
не пишется.

Срок хранения — `ANALYTICS_RETENTION_DAYS` (по умолчанию 365 дней).
Статистика по сотрудникам — персональные данные: Grafana закрыта паролем,
личные переписки на дашборде одной строкой «Личные переписки (все)», без
того, кто с кем.

## Установка

1. В `.env`:

   ```
   GRAFANA_ADMIN_PASSWORD=<длинный пароль>
   GRAFANA_ROOT_URL=https://chat.example.ru/grafana/
   ```

2. Поднять поверх основного compose:

   ```bash
   cd /opt/zweig-chat && git pull --ff-only
   sudo docker compose -f docker-compose.yml \
     -f deploy/docker-compose.grafana.yml up -d --build
   ```

3. Открыть `https://<домен чата>/grafana/`, войти как `admin` с паролем из
   `.env`. Дашборды — в папке «Zweig»: «Zweig — использование» (общий) и
   «Zweig — сотрудник» (выбор человека сверху).

При первом старте Grafana скачивает плагин `frser-sqlite-datasource` —
серверу нужен выход в интернет к `grafana.com`.

## Править дашборды

Запросы и раскладка — в `deploy/grafana/generate.py`. После правки:

```bash
python3 deploy/grafana/generate.py
```

и перезапустить Grafana (`sudo docker compose ... restart grafana`). Правки
через интерфейс Grafana не сохраняются: дашборды подключены из файлов.

Часовой пояс — переключатель «Часовой пояс» вверху дашборда (по умолчанию +3).
